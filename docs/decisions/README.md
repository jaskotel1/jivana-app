# Architecture Decision Records

An Architecture Decision Record (ADR) captures an important technical decision
along with its context and consequences. Create one when a decision has a
meaningful, long-term impact on architecture, dependencies, data boundaries, or
development practices. Routine implementation details do not need an ADR.

Name ADR files using:

```text
NNNN-short-decision-title.md
```

Use the next available four-digit number and a concise kebab-case title. Start
from [template.md](template.md), keep the decision focused, and update its
status when it is accepted, superseded, or deprecated.
